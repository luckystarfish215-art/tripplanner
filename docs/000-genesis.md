# TripsGen Genesis

Version: v0.1
Date: 2026-07-31

---

# Q0 - Why TripsGen?

ChatGPT provides answers.

TripsGen provides experiences.

---

# Q1 - What problem are we solving?

Travel planning is fragmented.

Users constantly switch between:

- Google Maps
- Reddit
- YouTube
- Instagram
- Blogs
- Booking websites

TripsGen combines everything into one experience.

---

# Q2 - Who are we building this for?

Primary audience:

- Couples
- Families
- Solo travellers
- First-time visitors

Secondary audience:

- Bloggers
- Digital nomads

---

# Q3 - What is TripsGen?

TripsGen is not an OTA.

TripsGen is an AI travel companion.

---

# Q4 - Core principles

- Mobile first
- SEO first
- Cache first
- Fast first
- Low cost
- Highly scalable

---

# Q5 - What should AI do?

AI should:

- Research
- Recommend
- Summarise
- Personalise
- Generate itineraries

AI should not:

- Build layouts
- Render maps
- Generate complete pages

---

# Core philosophy

AI generates intelligence.

Templates generate experiences.

---

# Generation pipeline

User
→ LLM
→ Structured JSON
→ Template engine
→ HTML5
→ Web / PDF / PNG

---

# Rendering strategy

70% templates

30% AI enhancement

---

# Image strategy

Avoid:

- Fully AI-generated pages
- Heavy GPU dependency
- Real-time image generation

Prefer:

- SVG assets
- Official tourism images
- Google Places photos
- HTML5 animation
